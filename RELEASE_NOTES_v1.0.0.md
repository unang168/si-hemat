## Si-Hemat v1.0.0 — Rilis Perdana

Aplikasi pencatatan & laporan keuangan pribadi dan keluarga Android yang **100% offline-first**, privat, mendukung **Sync Wi-Fi Keluarga terenkripsi**, dan **Asisten Gemini AI (Free Tier / BYOK)**.

### Sorotan Fitur
- **100% Offline SQLite & Mode Keluarga/Pribadi:** Pisahkan dompet/transaksi bersama keluarga dan pribadi secara rapi di semua tab (`Semua | Keluarga | Pribadi`).
- **Multi-Dompet, Transfer & Safe-to-Spend:** Mendukung tanggal gajian fleksibel (1–31 / akhir bulan, otomatis maju ke Jumat jika jatuh di Sabtu/Minggu).
- **Anggaran Bulanan & Tagihan Rutin + Tenor Cicilan:** Hapus/hentikan tagihan di bulan mendatang tanpa menghilangkan riwayat lunas bulan-bulan sebelumnya.
- **Riwayat Transaksi Modern:** Input nominal otomatis bertitik ribuan (`1.500.000`), subtotal harian, filter per dompet, kategori kustom, dan geser (*swipe*) hapus cepat dengan *Undo*.
- **Laporan Grafik Interaktif & Export:** Donut Chart & Bar Chart 6 bulan interaktif, drill-down rincian transaksi kategori, plus export **PDF & CSV**.
- **Sync Wi-Fi Lokal Terenkripsi:** Pairing QR Code + sinkronisasi 2 arah lewat Wi-Fi rumah dengan enkripsi **AES-256-GCM** (data pribadi tetap lokal).
- **Gemini AI Opsional (Gratis / BYOK):** Catat via Chat AI, Scan Struk/QRIS, dan Tanya Laporan memakai Google AI Studio API Key gratis Anda (`store: false`).
- **Keamanan & Backup:** Kunci PIN 6 digit + Biometrik dengan auto-lock, Mode Gelap/Terang, dan Backup/Restore terenkripsi `.sihemat`.

### File Unduhan
- **`Si-Hemat-v1.0.0-arm64-v8a.apk`** — Disarankan untuk sebagian besar HP Android modern (Samsung, Xiaomi, Oppo, Vivo, Pixel, dll.).
- **`SHA256SUMS.txt`** — Checksum verifikasi integritas file APK.

### Cara Install
1. Unduh **`Si-Hemat-v1.0.0-arm64-v8a.apk`** pada HP Android Anda.
2. Buka file APK → aktifkan izin **Install unknown apps** bila diminta Android → tekan **Install**.
3. *(Khusus pengguna yang sebelumnya memasang versi debug)*: Lakukan **Export Backup (`.sihemat`)** terlebih dahulu di menu Pengaturan, uninstall versi debug lama, install APK rilis ini, lalu **Pulihkan dari File Backup (`.sihemat`)**.
