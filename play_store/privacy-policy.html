Kebijakan Privasi Si-Hemat

Terakhir diperbarui: 27 November 2026 • Package ID: id.sihemat.si_hemat

Ringkasan Singkat: Si-Hemat dirancang 100% offline-first. Kami (pengembang) tidak mengumpulkan, menyimpan, menjual, atau mengakses data keuangan pribadi maupun keluarga Anda di server mana pun.

1. Penyimpanan Data Lokal

Seluruh catatan transaksi, dompet, kategori, anggaran, tagihan rutin, dan ringkasan laporan disimpan secara lokal di database SQLite pada perangkat Android Anda sendiri. Informasi sensitif seperti hash PIN aplikasi, kunci sinkronisasi keluarga, dan kunci API opsional disimpan secara terenkripsi menggunakan Android Keystore (flutter_secure_storage).

2. Sinkronisasi Keluarga (Wi-Fi Lokal)

Fitur sinkronisasi keluarga bekerja secara peer-to-peer hanya pada jaringan Wi-Fi lokal yang sama antar perangkat anggota keluarga yang telah dipasangkan melalui QR Code. Seluruh paket sinkronisasi dienkripsi end-to-end dengan AES-256-GCM dan verifikasi HMAC-SHA256. Data bertanda Pribadi tidak pernah dikirim keluar dari perangkat pemiliknya.

3. Fitur Asisten AI Opsional (Google Gemini API)

Fitur Catat via Chat AI, Scan Struk, dan Tanya Laporan bersifat sepenuhnya opsional dan hanya aktif apabila Anda memasukkan API Key Google AI Studio milik Anda sendiri. Saat Anda menggunakan fitur AI tersebut, teks input, gambar struk, atau ringkasan statistik yang Anda minta akan dikirim langsung dari perangkat Anda ke Google Gemini API dengan parameter store: false dan tunduk pada Ketentuan Layanan Google Gemini API. Pengembang Si-Hemat tidak memiliki server perantara dan tidak dapat melihat permintaan AI Anda.

4. Izin Perangkat yang Digunakan

  • Kamera (CAMERA): Digunakan hanya atas tindakan Anda untuk memindai QR Code undangan keluarga atau memotret struk belanja.
  • Jaringan & Wi-Fi (INTERNET, ACCESS_WIFI_STATE, CHANGE_WIFI_MULTICAST_STATE): Digunakan untuk menemukan perangkat keluarga di jaringan Wi-Fi lokal (mDNS) dan komunikasi opsional ke Google Gemini API.
  • Biometrik (USE_BIOMETRIC): Digunakan hanya jika Anda mengaktifkan fitur buka kunci sidik jari / wajah pada perangkat Anda. Data biometrik diproses sepenuhnya oleh sistem operasi Android.

5. Backup & Penghapusan Data

Anda dapat mengekspor file backup terenkripsi (.sihemat, AES-256-GCM + PBKDF2) ke penyimpanan pilihan Anda kapan saja. Karena data hanya tersimpan di perangkat Anda, menghapus data aplikasi atau mencopot pemasangan (uninstall) Si-Hemat akan menghapus seluruh data lokal secara permanen.

6. Privasi Anak

Si-Hemat ditujukan untuk pengelolaan keuangan pribadi dan keluarga oleh pengguna dewasa dan tidak secara sengaja mengumpulkan informasi pribadi dari anak di bawah usia 13 tahun.

English Summary

Si-Hemat is a 100% offline-first personal and family finance app. The developer operates no backend servers and does not collect, track, sell, or access your financial data. All records remain locally on your device. Optional Family Sync transfers only shared records over your local Wi-Fi network with AES-256-GCM encryption. Optional AI features use your own Google AI Studio API Key directly with Google Gemini API (store: false). Camera, Wi-Fi, and Biometric permissions are used strictly on-device when initiated by you.
